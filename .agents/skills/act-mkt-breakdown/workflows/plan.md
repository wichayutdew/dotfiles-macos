# Plan the breakdown

After reading the source report, prepare a concise working outline using the [breakdown plan template](../generic/plan-template.md). Identify the report outcome/boundaries, candidate work grouping and dependencies, story-detail requirements, and the proposed tracker destination/hierarchy or missing decisions.

Do not create items or treat report acceptance as publication approval. Planning is always a step but does not need a separate approval round unless explicit user/AGENTS instructions require one; otherwise continue to the complete backlog draft, then refine it with the user until explicit creation approval. Update this plan when material feedback changes scope or grouping.

# Present the report

Present the complete validated report or its readable canonical reference. Chat is the default destination; use the user's exact local file or existing document when requested. Do not require a local file for chat-only output.

Read the latest saved report before updating it. Reconcile concurrent edits and preserve unrelated content and finalized contracts. Save only the requested report; do not stage, commit, or modify product code as part of an investigation.

For a hosted destination, drafting and user review alone do not authorize publication. Show the exact content/destination and obtain any missing write approval, honor existing authorization, then read back saved content and identity. After a timeout, reconcile current content before retrying. Report local/unpublished drafts separately from confirmed hosted updates.

Invite the user to review the result and identify changes. On a revision, summarize material changes and present the updated report, not merely a progress note. Continue to [review and refine](review-report.md); delivery is not acceptance.

# Plan the investigation

After intake has established scope and resolved material scope questions, prepare and save `<workspace.root>/investigation-plan.md`, recording its absolute path in `.task-context.json`. Prepare this concise working plan using the [investigation plan template](../generic/plan-template.md). Ground it in the request, selected report format, current canonical report, sources, and latest user feedback.

Outline the questions, scope, evidence gathering, and report approach before research/drafting. A general question need not involve repositories, implementation, rollout, or telemetry. Keep evidence unknowns explicit and continue independent research within the established scope while clarifying them. If a new material scope choice emerges, discuss it before the affected research or drafting.

Planning is always a workflow step, but it does not add a separate upfront user approval gate unless explicit user/AGENTS instructions require one; otherwise continue within the established scope to research, validation, and the report-review loop. Revise the plan when feedback changes the questions or evidence required. Report acceptance and any hosted-write authorization remain separate from planning.

# Plannotator review procedure

Read the latest canonical document and preserve user edits. Save the complete current artifact, not an outline or summary. Reuse its canonical local file when it already contains suitable review context. For a narrow edit or a document whose requested content excludes review metadata, save a separate complete local review copy under the bound `workspace.root` per [task directory](task-directory.md). Explicit user/AGENTS-required review locations take precedence; record that actual path in `.task-context.json`. Retain the canonical source/destination and the exact reviewed version in the continuation record. A local review copy does not authorize hosted publication. State the review purpose described below in the review copy or invocation context; keep process metadata out of the canonical document when it is outside the requested content. Resolve any required input first, while continuing independent drafting/research. Record the pending decision and continuation state, and state the exact actions approval would authorize.

Submit the artifact to Plannotator Inbox as an attachment with a `:::question` requesting explicit approval or feedback. Notify the user with the review reference and end the turn; do not poll, wait for the decision, launch a blocking CLI session, or open duplicate reviews. If Inbox is unavailable, report the blocker and provide the artifact path. Honor an explicit user choice of another review interface.

On a later response, reconcile the same artifact and review record. Explicit approval of the current artifact and scoped actions permits the next stage; carry approval notes forward without routine reconfirmation. On feedback, revise the same artifact, validate it, submit the revised version for review, notify the user, and end that turn. Dismissal, silence, elapsed time, a submission acknowledgment, failure, or approval of a materially different version is not approval. Reuse valid explicit approval without reopening the gate.

## Review purpose and next action

State that approval accepts this investigation report only. After approval, finish with the accepted report reference and material limitations. Do not implement it, create tracker items, or start breakdown automatically. Feedback returns to research as needed, validation, presentation, and another review of the revised complete report.
